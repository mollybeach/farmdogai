# Farm Dog AI

🐶🌾  Farm Dog AI is an innovative application designed to assist farmers in tracking and managing their coin resources using advanced AI technology. This tool aims to optimize farming operations by providing real-time insights and analytics on coin usage, helping farmers make informed decisions.

## Overview

Farm Dog AI leverages artificial intelligence to monitor and analyze coin transactions and usage within farming operations. By integrating with various data sources, it provides farmers with actionable insights to enhance productivity and resource management.

## Features

- **AI-Powered Tracking**: Utilize machine learning algorithms to track coin usage and predict future needs.
- **Real-Time Analytics**: Get instant insights into coin transactions and usage patterns.
- **User-Friendly Interface**: An intuitive dashboard that makes it easy for farmers to visualize their data.
- **Alerts and Notifications**: Receive alerts for unusual coin activity or when thresholds are reached.
- **Integration with Farming Tools**: Seamlessly connect with existing farming management systems for a holistic view of operations.

## Tech Stack

- **Frontend**: Next.js, React
- **Backend**: AWS Amplify, AWS AppSync
- **Database**: Amazon DynamoDB
- **Styling**: Tailwind CSS
- **Development Tools**: TypeScript, ESLint, Prettier

## Getting Started

To get started with Farm Dog AI, follow these steps:

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/mollybeach/farm-dog-ai.git
   cd farm-dog-ai
   ```

2. **Install Dependencies**:
   ```bash
   npm install
   ```

3. **Run the Application**:
   ```bash
   npm run dev
   ```

4. **Access the Application**: Open your browser and navigate to `http://localhost:3000`.
